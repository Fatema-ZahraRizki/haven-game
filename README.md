# Before Nightfall

A 2D platformer game made with Godot.

## About the Game

**Before Nightfall** is a 2D platformer where you have to make your way home before nightfall.

The game starts during the day, but as time passes, the environment changes from afternoon to sunset, dusk, and finally night. You have a limited amount of time to reach the end of the level before night falls.

Explore the environment, avoid obstacles, and make it home in time.

## Controls

* **A / D** — Move left and right
* **W** — Jump

## Gameplay

The background changes as time passes, progressing through different stages of the day (25 seconds each):

* Day
* Afternoon
* Sunset
* Dusk
* Night

A countdown shows how much time is left before sunset.

Reach the dead tree at the end of the level to finish the game before nightfall.
